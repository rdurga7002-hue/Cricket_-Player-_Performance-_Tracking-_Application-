# Phase 5 – Salesforce Development

## Developer Account

A Salesforce Developer Account was created for developing the CRICKSTATS application.

## Object Creation

### Player Object
A custom Salesforce object named **Player** was created to store player information.

### Match Performance Object
A custom Salesforce object named **Match Performance** was created to store match-wise player performance information.

## Object Configuration

The project includes custom fields for storing player and match performance details.

### Player Object
- Player Name
- Player Number
- Profile Picture
- Date of Birth
- Role
- Batting Style
- Bowling Style
- Nationality
- Team

### Match Performance Object
- Match Performance Name
- Player of the Match
- Match Result
- Runs Scored
- Balls Faced
- Fours
- Sixes
- Overs Bowled
- Wickets Taken
- Runs Conceded
- Maiden Overs
- Stumpings
- Catches
