# Phase 6 – UI & Application Configuration

## Custom Tabs

Custom tabs were created to provide access to the project objects through the Salesforce interface.

## Lightning App

A Salesforce Lightning App named **CRICKSTATS** was created for the application.

## Navigation Items

The CRICKSTATS application includes:

- Players
- Match Performances
- Reports
- Dashboards

## Application Configuration

The Lightning App provides navigation to player records, match performance records, reports and dashboards.

## User Interface

The application was configured using Salesforce Lightning to provide a structured interface for managing and analysing cricket player performance.
