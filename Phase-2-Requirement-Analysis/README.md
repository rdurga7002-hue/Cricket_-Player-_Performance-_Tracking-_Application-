# Phase 2 – Requirement Analysis

## Functional Requirements

### 1. Player Registration
The system should allow users to register and manage player details.

### 2. Match Performance Entry
The system should allow users to enter match performance details.

### 3. Dashboard Generation
The system should provide dashboards for analysing player performance.

### 4. Report Creation
The system should generate reports based on player and match performance data.

### 5. Flow Automation
The system should support automation using Salesforce Flows.

## Non-Functional Requirements

- Usability
- Security
- Reliability
- Performance
- Availability
- Scalability
